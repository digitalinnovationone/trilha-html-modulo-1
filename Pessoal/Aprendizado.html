Lista não Ordenada:

Listas Não Ordenadas são criadas a partir da tag < ul >. E Seus itens são definidos através da tag < li >. Exemplo:

  • Item 1
Uma característica das listas não ordenadas são que elas são demarcadas por bolinhas. Para ver detalhadamente sugiro que você inspecione o site e confira toda a estrutura.

Lista Ordenada:

Listas Ordenadas são criadas a partir da tag < ol >. E Seus itens são definidos através da tag < li >. Exemplo:

  1. Item
  2. Item
  3. Item
Uma característica das listas ordenadas são que elas são demarcadas por números. Para ver detalhadamente sugiro que você inspecione o site e confira toda a estrutura.

Estrutura Básica HTML:

toda estrutura HTML deve iniciar com < !DOCTYPE html > Que serve para declarar e informar aos navegadores que o documento se trata de um arquivo HTML.

Todo documento deve iniciar com uma tag < html > e fechar com < /html >
E dentro dessa tag deve-se abrir outra tag, a tag < body > < /body >.

E é dentro desta tag que ficara todo o conteúdo vísivel da página HTML.

Tipos de Inputs:

Inputs são campos utilizados em formulários para receber valores e informações dos usuários. Existem diversos tipos, como campos para nome, data, números, e-mail, senha, caixa de seleção (checkbox), entre muitos outros.
