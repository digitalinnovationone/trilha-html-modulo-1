Estrutura básica do HTML

A estrutura básica de um documento HTML consiste em três elementos principais: <html>, <head> e <body>.

  • A tag html é o elemento raiz de um documento HTML e contém todo o conteúdo da página.
  • A tag head contém informações sobre o documento HTML que não são visíveis na página, mas são importantes para o navegador e outros serviços web.
  • A tag body contém o conteúdo visível da página, como: texto, imagens, vídeos, etc.

Além disso, incluímos no início do arquivo html a linha <!DOCTYPE html> que informa ao navegador que o documento é um documento HTML5.

▲

O que são tags?

As tags são elementos de marcação que permitem que o navegador entenda como interpretar e exibir o conteúdo de uma página web. As tags são escritas dentro dos símbolos < > e geralmente vêm em pares: uma tag de abertura e uma tag de fechamento, por exemplo: <p> e </p> respectivamente.

Existem diversos tipos de tags, cada uma com sua função específica, como tags para cabeçalhos, parágrafos, títulos, links, imagens, listas, etc.

As tags aprendidas neste Módulo

<h1> até </h6> Define um título, sendo que o número indica diferentes níveis, com h1 sendo o mais importante e h6 o menos
<p> Define um parágrafo de texto
<br> Insere quebras de linha simples em um texto
<b> Formata o texto como negrito, mas sem definir importância para o texto
<i> Formata o texto como itálico, mas só deve ser usada quando não houver uma tag semântica mais apropriada
<u> Formata o texto com um sublinhado
<strong> Define o texto como importante no documento e o texto é exibido em negrito
<em> Define o texto como enfatizado no documento e o texto é exibido em itálico
<mark> Define o texto como marcado ou destacado e o texto pode ser exibido com um fundo amarelo
<small> Define o texto com tamanho menor do que o padrão do texto ao redor
<blockquote> Define uma citação de outra fonte
<code> Define o texto como código de computador no documento
<a> Define um link para outras páginas web ou até mesmo para outras seções dentro da mesma página
<img> Define uma imagem
<div> Define uma divisão em um documento e pode ser usada para agrupar e aplicar estilos com CSS
<span> Define um agrupamento embutido em uma parte de um texto ou de um documento para aplicar estilos com CSS
<ul>, <ol>, <li> Define listas não ordenadas, ordenadas e itens de lista, respectivamente
<table>, <tr>, <td> Define tabelas com linhas e colunas
<form> Cria um formulário HTML e pode conter um ou mais elementos para entrada do usuário
