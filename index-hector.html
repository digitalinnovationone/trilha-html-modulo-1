HTML - Semântica

Voltar

A semântica no HTML define o significado e a função dos elementos, ajudando navegadores e leitores de tela a interpretar o conteúdo corretamente. Tags como <header>, <main> e <footer> indicam claramente suas funções. Isso melhora o SEO e a acessibilidade. O uso correto da semântica torna o código mais organizado e legível. É essencial para uma web estruturada e eficiente.

Mudanças do HTML 5

Voltar

O HTML5 introduziu novas tags semânticas, suporte nativo para áudio e vídeo e recursos para aplicações offline. Também trouxe melhorias para formulários, como novos tipos de input. A padronização entre navegadores foi fortalecida. APIs integradas facilitaram o acesso a recursos como geolocalização e canvas. Tornou o desenvolvimento mais moderno e interativo.

Acessibilidade

Voltar

A acessibilidade garante que sites possam ser usados por pessoas com diferentes limitações. Inclui boas práticas como texto alternativo em imagens e uso correto de headings. ARIA e navegação por teclado são recursos importantes. A acessibilidade amplia o alcance do conteúdo. Também é requisito em muitos padrões e legislações.

Web Scraping

Voltar

O web scraping é a extração automatizada de dados de sites. É feito com linguagens como Python, usando bibliotecas como BeautifulSoup e Selenium. Pode ser usado para coleta de preços, pesquisas e análise de dados. É importante respeitar regras de uso e políticas de privacidade. Uso indevido pode gerar problemas legais.

Main, Header e Footer

Voltar

No HTML5, <main> representa o conteúdo principal da página, único e relevante. O <header> contém elementos de introdução e navegação inicial. Já o <footer> exibe informações finais, como direitos autorais e links adicionais. Essas tags melhoram a organização do conteúdo. Também ajudam em SEO e acessibilidade.

Aside, Section e Nav

Voltar

<aside> é usado para conteúdos complementares, como barras laterais. <section> agrupa conteúdo relacionado com título próprio. <nav> contém menus de navegação principais ou secundários. O uso correto dessas tags cria uma hierarquia clara. Isso facilita a leitura por humanos e máquinas.

Article, Blockquote e Q

Voltar

A tag <article> representa conteúdo independente e completo, como posts, notícias ou comentários. Pode ser reutilizado ou distribuído fora da página principal. Deve conter título e conteúdo próprio. Ajuda mecanismos de busca a entender a estrutura. É ideal para conteúdo autossuficiente.

A tag <blockquote> é usado para citações longas e geralmente vem com recuo. <q> serve para citações curtas embutidas no texto. Ambos ajudam a destacar conteúdos citados de outras fontes. Podem incluir o atributo cite com a origem. São importantes para clareza e credibilidade.

Figure, Figcaption e Picture

Voltar

<figure> agrupa conteúdo visual como imagens ou gráficos, com contexto independente. <figcaption> adiciona legenda ao conteúdo do figure. <picture> permite uso de diferentes imagens para diferentes tamanhos de tela. Juntas, essas tags aumentam a flexibilidade e acessibilidade. Melhoram a apresentação visual no HTML5.

Resenha - O que é SEO

Voltar

SEO (Search Engine Optimization) é o conjunto de técnicas para melhorar o posicionamento de um site nos mecanismos de busca. Envolve otimização de conteúdo, palavras-chave, links e estrutura. Também inclui melhorias de velocidade e experiência do usuário. Um bom SEO aumenta o tráfego orgânico. É essencial para visibilidade online.
