  1. h1 até h6 = H significa Heading, cabeçalho. temos 6 tipos, a diferença deles são o tamanho. h1 é o maior e o h6 o menor.

  2. p = a tag p, significa parágrafo. se você quer escrever um texto e deixar ele bem alinhado, essa é a tag que você precisa usar.

  3. mark = o nome é bem intuitivo, é um efeito igual a um marcador de texto.

  4. small = deixa o texto bem pequeno.

  5. i = Deixa o texto em modo Itálico.

  6. u = com o u podemos deixar o texto sublinhado.

  7. strong = assim como a tag "b", strong deixa o texto em Negrito.

  8. ol ou ul = usamos para fazer listas, ol podemos fazer listas como essa
    e ul podemos fazer como essas da página anterior. ambos utilizando a tag "li" dentro dela.

  9. a = significa âncora. ou resumidamente, uma forma de colocar um link, como no numero 8.

  10. blockquote = usada para destacar uma citação longa de outro autor ou fonte.

    "Geralmente, o navegador exibe o conteúdo dessa tag com recuo (margem à esquerda) para diferenciá-lo do restante do texto."

  11. sub = você pode usar para colocar textos ligeiramente abaixo da linha base do texto normal.

  12. sup = podemos exemplificar essa tag fazendo isso: preciso alugar um apartamento de 40m2
    mais usado em fórmulas matemáticas.
