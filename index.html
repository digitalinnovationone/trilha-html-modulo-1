Desafio final sobre HTML

Projeto final visando melhorar as práticas de HTML com acessibildade

Itens importantes:

  • Títulos: Temos variados tamanhos de títulos

    H1

    H2

    H3

    H4

    H5
    H6
  • Mark: Destaca o texto
  • Small: Dexa o texto menor
    • Ol: Cria uma lista ordenada:
    1. 1º Lugar
    2. 2º Lugar
    3. 3º Lugar
  • I: Deixa o texto em itálico
  • U: Sublinha o texto
  • Strong: Semanticamente ressalta a palavra ou frase, deixa no estilo negrito por padrão
  • Sub: Deixa o item como subscrito ex: H2O
  • Sup: Deixa o item como sobrescrto ex: x2

Tags sugeridas para estudar:

  • Del: Marca o texto como removido, dexa o estilo como riscado
  • Font: Aparentemente obsoleto, era usado para dedfnir a fonte, cor e tamanho do texto.
    Com a chegada do CSS a usabilidade não foi mais necessária.
  • Abbr: Abreviação
  • Blockquote:
    Citação em bloco, estilo recuado por padrão
  • P: apenas um parágrafo de texto
