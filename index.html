História dos computadores

(Voltar)
A palavra “computador” vem do verbo “computar” que, por sua vez, significa “calcular”. Sendo assim, podemos pensar que a criação de computadores começa na idade antiga, já que a relação de contar já intrigava os homens.

A história dos computadores é uma jornada fascinante que começa com dispositivos mecânicos simples, como o ábaco, e evolui para as máquinas eletrônicas avançadas que conhecemos hoje.

Nos anos 1940, os primeiros computadores digitais eletrônicos, como o ENIAC, foram desenvolvidos, revolucionando o processamento de dados.

Durante as décadas seguintes, a miniaturização dos componentes levou à criação dos computadores pessoais nos anos 1970 e 1980. Com o desenvolvimento da internet, os computadores se tornaram essenciais para a comunicação global e o compartilhamento de informações.

O que são Clients?

(Voltar)

Em redes de computadores, um client (ou cliente) é um dispositivo ou programa que solicita serviços ou recursos de um servidor. Os clientes são típicos em modelos de computação baseados em rede, onde a interação do usuário ocorre.

Exemplos comuns de clientes incluem navegadores da web, que solicitam páginas de um servidor web, e aplicativos de e-mail que acessam servidores de correio.

Basicamente, os clientes facilitam o acesso a informações e serviços remotos, enquanto os servidores processam e provêm essa informação.

O que são Servers?

(Voltar)

Servers (ou servidores) são computadores poderosos ou programas que fornecem serviços, dados ou recursos para outros computadores, conhecidos como clientes. Eles desempenham funções essenciais em redes, hospedando sites, armazenando arquivos, gerenciando e-mails e mais.

Os servidores podem ser dedicados para executar tarefas específicas, como web servers, que entregam páginas web, ou file servers, que armazenam e gerenciam arquivos.

A robustez e a alta disponibilidade são características-chave dos servidores para garantir que recursos estejam sempre acessíveis.

Estrutura basica do HTML

(Voltar)

O HTML (HyperText Markup Language) é a espinha dorsal da web, definindo a estrutura e o layout das páginas.

A estrutura básica começa com <!DOCTYPE html> para declarar o uso do HTML5, seguido pelas tags <html>, <head>, e <body>. O <head> contém metadados, links para CSS e scripts, enquanto o <body> abriga o conteúdo visível da página, organizado com tags de texto, imagens, links, e muito mais.

Listas Ordenadas X Listas Não Ordenadas

(Voltar)

As listas são elementos fundamentais para organizar informações em HTML. Uma lista ordenada, criada com <ol>, automaticamente numera os itens dentro dela, ideal para instruções sequenciais ou classificações.

Cada item é representado por <li>. Em contraste, uma lista não ordenada usa <ul>, apresentando itens com marcadores, perfeita para listas sem prioridade ou ordem específica.

Ambas são úteis para estruturar dados de maneira clara e concisa.

Tags HTML de Texto

(Voltar)

Abaixo, segue uma lista de algumas tags usadas na formatação e formação de Textos em HTML:

  • <h1> a <h6>: Tags de cabeçalho, usadas para títulos e subtítulos, onde <h1> é o mais importante e <h6> o menos.
  • <p>: Denota um parágrafo de texto.
  • <mark>: Destaca o texto como se estivesse marcado com um marcador.
  • <small>: Reduz o tamanho do texto, indicativo de notas de rodapé ou detalhes menos importantes.
  • <i>: Aplica itálico ao texto, muitas vezes para ênfase.
  • <u>: Sublinhar o texto.
  • <strong>: Dá ênfase forte ao texto, geralmente exibido em negrito.
  • <a>: Cria um hiperlink, permitindo a navegação para outra URL.
  • <hr>: Insere uma linha horizontal, usado para separar conteúdo.
  • <sub>: Exibe texto como sobrescrito, usado para notações científicas.
  • <sup>: Exibe texto como sobrescrito, comum em expoentes.
  • <blockquote>: Denota uma citação em bloco, geralmente formatada com um recuo.
  • <del>exto que foi excluído ou removido de um documento, geralmente exibido com um risco (traço) no meio.
  • <font>: Antigamente usada para definir a cor, fonte e tamanho do texto. Está obsoleta no HTML5; agora, recomenda-se usar CSS para estilização.
