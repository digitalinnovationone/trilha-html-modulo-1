O que são as Tags HTML?

Voltar ao índice

As Tags HTML são utilizadas para informar e definir tudo o que virá ser um site. As Tags tem como característica estarem dentro de sinais "<>" e tudo o que tiver dentro delas será mostrado em tela.

Principais Tags HTML

Voltar ao índice

Tag html

A tag html é o elemento básico da estrutura do HTML. Assim sendo, ela conterá todos os elementos do seu documento. Todo documento HTML deve iniciar e finalizar com essa tag.

Tag head

A tag head delimita o cabeçalho do documento. Não possui nenhum valor visível, porém é capaz de transmitir ao navegador diversas informações muito úteis e essenciais a uma boa apresentação do seu documento HTML;

Tag title

Essa tag define o título da sua página, o nome que aparecerá na sua aba, janela ou guia. Por esta razão, a tag titleé de grande importância para o SEO;

Tag body

A tag body representa o corpo do documento. Em síntese, é nessa tag que todos os elementos visíveis do seu site devem ser inseridos.

Tags HTML de conteúdo

Voltar ao índice

Tag p

Principal tag de texto, compõe um parágrafo;

Tag span

Apesar de ter uma funcionalidade e características parecidas com os parágrafos (tag p), costumam ser utilizadas apenas para pequenas informações, como legendas de um formulário, legendas de uma imagem, etc. Também pode ser utilizada para formar um container;

Tag b

Transforma o conteúdo em negrito;

Tag i

Transforma o conteúdo em itálico;

Tag br

A tag br executa a função de quebra de linha;

Tag hr

A tag hr forma uma linha horizontal.
