Introdução ao HTML

Neste módulo, aprendemos que HTML é a linguagem usada para estruturar o conteúdo de páginas da web. Aprendemos sobre:

Tags

São comandos usados para dizer ao navegador o que mostrar. Exemplos: <head>, <body>, <a> (links), <ul> e <ol> (listas), <li> (itens da lista), e os títulos de <h1> a <h6>.

Atributos

São informações extras nas tags, como o href usado para definir o destino de um link.

Trabalhando com Formulários

Aprendemos a criar formulários para coletar informações do usuário, como nome, idade ou preferências.

Principais Tags

Usamos <form> para iniciar um formulário, <input> para campos de texto, <checkbox> e <radio> para opções, <button> para enviar, <select> e <textarea> para listas e áreas de texto maiores.

Atributos

São usados para configurar os campos, como type, name, value, entre outros.

Estruturando HTML + Formatações

Estudamos como organizar a página e como deixar o texto com diferentes estilos.

Formatação de Texto

Aprendemos tags como <strong> para negrito, <i> e <b> para itálico ou negrito, <u> para sublinhado, e <font> para alterar cor e tamanho (embora seja pouco usada no HTML5).

Estruturação

Tags como <div> e <span> servem para agrupar conteúdos. Também vimos <fieldset> para agrupar campos em formulários e <iframe> para mostrar outros sites dentro da página.

Trabalhando com Mídias utilizando HTML

Aprendemos a inserir imagens, vídeos e áudios nas páginas web.

Tags de Mídia

Usamos <img> para imagens, <audio> e <video> para som e vídeo, <track> para legendas, e <iframe> para embutir vídeos do YouTube ou mapas do Google.

Trabalhando com Tabelas

Aprendemos a organizar informações em forma de tabela.

Tags de Tabela

<table> inicia a tabela. Dentro dela usamos <tr> (linhas), <th> (cabeçalhos), <td> (células de dados), além de <thead>, <tbody>, <tfoot> e <caption> para organizar melhor a estrutura.

HTML Semântico

Vimos que o HTML semântico ajuda os navegadores e leitores de tela a entenderem melhor o conteúdo da página.

Estrutura Semântica

Aprendemos tags como <main>, <header>, <footer>, <nav>, <section>, <aside>, <figure>, <figcaption> e <picture>. Essas tags ajudam na organização e acessibilidade.

Outros Conceitos

Falamos também sobre a importância de criar páginas acessíveis para todos, sobre web responsiva (que se adapta a diferentes telas) e o conceito de web scraping (extração de dados de páginas).
