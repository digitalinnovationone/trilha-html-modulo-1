Breve história do HTML

O HTML (HIPER TEXT MARKUP LANGUAGE), como o próprio nome já diz, ao contrário do que pensam, não é uma linguagem de programação — é uma linguagem de marcação de hipertexto. Portanto, entende-se que é uma linguagem estrutural. Seu início se deu na década de 1990, quando o então físico britânico Tim Berners-Lee1 criou o HTML original (e outros protocolos associados como o HTTP), numa estação NeXTcube, usando o ambiente de desenvolvimento NeXTSTEP.

Aplicações do HTML

O HTML é amplamente utilizado, tanto por sua facilidade de uso diante de outras linguagens de marcação, quanto porque se tornou um padrão ISO.

Esse padrão tornou o HTML uma linguagem padronizada em todo o mundo. Estima-se que 98% dos sites que usam a internet utilizam o HTML, e 100% dos sites que seguem o padrão W3C (WWW) usam essa linguagem.
