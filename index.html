O que são as tags <img>?

↑ Voltar ao topo

A tag <img> é usada para adicionar uma imagem em uma página HTML.

As imagens podem ter origem através de outras páginas web ou de forma local.

A tag <img> tem dois atributos obrigatórios:

  • src - Especifica o caminho para a imagem "link" ou o caminho local
  • alt - Especifica um texto alternativo para a imagem, se por algum motivo a imagem não puder ser exibida

O que são as tags <video>?

↑ Voltar ao topo

A tag <video> é usada para incluir um vídeo em uma página HTML.

A tag <video> contém o atributo src que especifica o caminho para o vídeo através do "link" ou o caminho local.

O que é Web Scraping?

↑ Voltar ao topo

É a extração de dados de websites de maneira automatizada via robôs ou bots, convertendo esses dados de uma maneira estruturada e útil para análise, sendo utilizada de diversas formas.

O que são listas ordenadas e não ordenadas?

↑ Voltar ao topo

A principal diferença entre a lista ordenada e a lista não-ordenada está na maneira com que os itens de cada lista são apresentados - a lista ordenada enumera os elementos; a lista não-ordenada coloca marcadores antes de cada elemento.

Uma lista ordenada é delimitada pelas etiquetas <ol> e </ol> (Ordered List). Cada item da lista é delimitado pelas etiquetas <li> e </li> (List Item).

A estrutura da lista não-ordenada é semelhante à da lista ordenada - porém, ao invés de ser construída com o elemento ol, é construída com o elemento ul (Unordered List).
