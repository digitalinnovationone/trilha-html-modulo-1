Tags de formatação

São tags que ajudam a aprimorar e organizar a experiência do(s) usuário(s) ao ler um texto de uma imagem, podendo modifica-las dentro de um contexto, como exemplo; em títulos, citações, paragrafação, ordenamentos, paragrafação e outros. Essas tags são muitos importantes, pois elas definem as funcionalidades que cada area do site será atribuído de acordo com as necessidades e de seu propósito.

Exemplos de tags de formatação "< >":

  • time - Usado com o atributo datetime, tem a função de marcar valores de data e hora com peso semântico, ou seja, é entendido tanto pelo computador quanto pelo usuário. Pode ser definido pela data e hora, só a data ou só às horas dentro das aspas do atributo, ex:"datetime="2025/07/01T20:30">hoje às 20:30h"
  • i - Deixa o termo escrito em itálico, normalmete usado para citações ou estrangeirismos. Aliás, esta tag está sendo usada neste texto.
  • mark - Ele é usado para destacar um termo a se ter atenção ou interesse
  • a - Versátil, esta tag é comumente conhecida como "âncora", ou seja, ela cria um link entre outras partes de um site, até dentro da mesma página ou entre outros sites.

Atributos das Tags no HTML

São "marcadores" que indicam uma função específica àquela tag. Não terá efeito em codigos não identados pertencentes a ela, sendo necessário toda vez sua utilização em tags não identadas.

Exemplos de Atributos"":

  • class - Este atributo premite que você aplique recursos do CSS e JavaScript em arquivos identados.
  • href - Usado em tags relacionado à links, ele define aonde esse elemento será destinado.
  • id - É usado para identificar um elemento específico, não podendo ser utilizado o atributo "id" duas vezes para o mesmo elelmento em uma página.

Imagens, Áudios e Vídeos

São anexações de aquivos externos cujo objetivo, é de enrriquecer o conteúdo da página, seja para referências, ou adicionar informações oriundas de outras fontes de cunho educativo, informativo(notícias) e outros.

Exemplos de Tags Imagens, Audios e Vídeos "< >"

  • img - Esta tag, adiciona uma ou mais imagens à página, ela é muito interessante pois, ajuda na ilustração de textos, representações de matérias jornalisticas e de curiosidades.
  • Figcaption - Insere uma descirção de imagem, exibindo informações adicionais ao referido.
  • Source - define a fonte que mídia de imagem, audio e/ou vídeo foi retirado.
  • audio e video - Insere um tipo de audio e/ou vídeo à pagina ou site.

As tags Style e Script (Bônus)

São tags que importam funcionalidades de CSS e JavaScript, onde, poder-se-á ser feito codigos das duas linguagens dentro do arquivo HTML ou linkar arquivos diferentes para o HTML, atribuindo todas as funcionalidades que essas linguagens podem fornecer ao projeto.
