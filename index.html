O que é HTML5?

HTML5 é a quinta e mais recente versão oficial do HTML (HyperText Markup Language), a linguagem padrão para criar e estruturar conteúdo na web.
Ele foi desenvolvido pelo W3C (World Wide Web Consortium) com o objetivo de modernizar o HTML e torná-lo mais adequado às necessidades da web moderna.

(Início)

O que são Tags?

Tags são elementos usados para marcar e estruturar o conteúdo de uma página HTML.
Elas informam ao navegador como exibir o conteúdo.

(Início)

O que são Atributos em HTML?

Atributos são informações extras fornecidas às tags HTML para modificar seu comportamento, aparência ou funcionalidade.
Eles ficam dentro da tag de abertura.

(Início)

O que é Estrutura Semântica?

É a organização do HTML usando tags que têm significado claro sobre o conteúdo que elas contêm.

(Início)
