História dos computadores

Os computadores surgiram para facilitar cálculos e o processamento de informações. Inicialmente, eram máquinas enormes ocupando salas inteiras. Com o tempo, evoluíram para dispositivos cada vez mais compactos e potentes. Hoje, são indispensáveis na vida cotidiana e na ciência. Para saber mais, visite Wikipedia - Computador.

"Um computador é um dispositivo capaz de executar algoritmos, processando dados de acordo com instruções armazenadas."

Alguns computadores antigos tinham marcações específicas: IBM 701 foi um modelo pioneiro.

O que são Clients?

Um client é um programa ou dispositivo que solicita serviços de outro programa chamado server. É responsável por enviar pedidos e exibir resultados para o usuário. Por exemplo, navegadores como Google Chrome e Firefox são clients que requisitam páginas web.

Exemplo de abreviação: HTTP é usado pelos clients para se comunicar com os servers.

(Voltar)

O que são Servers?

Um server é um computador ou programa que fornece serviços a clients na rede. Ele processa requisições, envia dados e gerencia recursos. Por exemplo, servidores web como Apache ou Nginx respondem a pedidos de páginas HTML.

Às vezes os servidores indicam versões antigas de software como alerta para atualização.

(Voltar)

Como é uma estrutura básica de um HTML?

Uma página HTML possui uma estrutura organizada em: <!DOCTYPE html>, <html>, <head> e <body>. Dentro do body, colocamos conteúdos como títulos, parágrafos, listas e links. Exemplo básico: 

<!DOCTYPE html>
<html>
  <head>
    <title>Título da Página</title>
  </head>
  <body>
    <h1>Olá Mundo</h1>
    <p>Meu primeiro site</p>
  </body>
</html>

Também é possível usar tags antigas como font para estilo de texto, mas o recomendado é usar CSS.

Entendendo a diferença entre listas ordenadas e não ordenadas

As listas no HTML podem ser ordenadas ou não ordenadas. - Ordenadas (<ol>): cada item possui uma numeração sequencial. - Não ordenadas (<ul>): os itens são marcados com bolinhas ou outros símbolos.

Exemplos:

  1. Item 1 subtexto
  2. Item 2 superscript
  3. Item 3
  • Item A
  • Item B
  • Item C
