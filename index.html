Sobre o projeto:

A ideia do desafio, se consiste em criar uma página HTML utilizando tags que vimos nas aulas.
Porém, também temos que utilizar algumas que ainda não vimos...

Por Exemplo:

  • font:

    A tag font: foi usada nas versões mais antigas do HTML para alterar a aparência do texto, como a cor, o tamanho e o tipo de fonte. No entanto, essa tag foi descontinuada no HTML5 porque a estilização de texto agora é feita com CSS (Cascading Style Sheets), que é uma maneira mais moderna e eficiente de aplicar estilos.

  • del:

    A tag DEL em HTML é usada para marcar texto que foi excluído ou removido em um documento. O texto dentro dessa tag aparece riscado na página, indicando que ele foi removido ou que está obsoleto.

  • p:

    A tag "p" em HTML é usada para definir parágrafos de texto em um documento. Ela é uma das tags mais básicas e importantes para a estruturação de conteúdo em páginas web.
