História dos computadores

Os computadores evoluíram muito ao longo dos anos. No início, eram máquinas enormes e muito caras. Hoje, conseguimos carregar computadores no bolso através dos celulares.

A primeira geração utilizava válvulas eletrônicas, enquanto as gerações seguintes passaram a utilizar transistores e microprocessadores.

“A tecnologia move o mundo.” — Steve Jobs

Atualmente, os computadores são essenciais para estudos, trabalho e comunicação.

O que são Clients?

Clients são os dispositivos ou programas que fazem requisições para acessar informações em um servidor.

Navegadores como Google Chrome, Firefox e Edge são exemplos de clients.

Quando digitamos um endereço de site, o client envia uma solicitação ao servidor e recebe uma resposta.

Exemplos de Clients

  1. Navegadores
  2. Aplicativos mobile
  3. Programas desktop

O que são Servers?

Servers são computadores responsáveis por armazenar dados e responder às solicitações dos clients.

Eles hospedam sites, aplicações e bancos de dados.

Um servidor funciona praticamente 24 horas por dia para manter os serviços online.

Funções dos servidores

  • Armazenar arquivos
  • Processar dados
  • Responder requisições

Como é uma estrutura básica de um HTML?

Todo documento HTML começa com a declaração <!DOCTYPE html>.

Depois utilizamos a tag <html>, que contém todo o conteúdo da página.

Principais partes do HTML

  1. head → configurações da página
  2. title → título exibido na aba
  3. body → conteúdo visível

O HTML é considerado a estrutura principal de um site.

Importante

Sem HTML, o navegador não conseguiria interpretar corretamente o conteúdo.

Entendendo a diferença entre listas ordenadas e não ordenadas

As listas ajudam na organização das informações.

Lista Ordenada

Utilizamos a tag <ol> quando a sequência importa.

  1. Ligar o computador
  2. Abrir o navegador
  3. Acessar um site

Lista Não Ordenada

Utilizamos a tag <ul> quando a ordem não faz diferença.

  • HTML
  • CSS
  • JavaScript
